# Produkte teilen & Einladungen

## Warum Produkte teilen?

Du möchtest, dass eine andere Person (z. B. dein Team, dein Partner, ein Mitarbeiter) auf deine Domains, Server oder andere Produkte zugreifen kann? Kein Problem – du kannst sie freigeben!

---

## So teilst du ein Produkt

### Schritt 1: Öffne das Produkt

Gehe zu einem deiner Produkte, z. B:
- Domain: **https://dash.forgehost.de/domains**
- Webspace: **https://dash.forgehost.de/webspace-accounts**
- VPS/Server: **https://dash.forgehost.de/vps/instances**
- Gameserver: **https://dash.forgehost.de/gaming-accounts**

### Schritt 2: Klicke auf Teilen

1. Öffne das Produkt, das du teilen möchtest
2. Suche nach dem Tab oder Button **Teilen** oder **Freigeben**
3. Klicke darauf

### Schritt 3: Lade die Person ein

1. Gib die **E-Mail-Adresse** der Person ein, die Zugriff haben soll
   - Die Person muss bei ForgeHost registriert sein (oder erhält einen Registrierungs-Link)
2. Wähle, welche **Rechte** sie haben soll:
   - **Vollzugriff**: Sie kann alles machen wie du (DNS ändern, Dateien hochladen, etc.)
   - **Nur ansehen**: Sie kann nur schauen, aber nichts ändern
3. Klicke auf **Einladung absenden**

### Schritt 4: Person akzeptiert die Einladung

Die eingeladene Person erhält eine **E-Mail mit einem Link**. Sie klickt darauf oder besucht **https://dash.forgehost.de/invitations/accept-product** und akzeptiert.

✅ **Fertig!** Das Produkt erscheint jetzt in ihrer Produktliste.

## Freigaben verwalten

### Berechtigungen ändern

Möchtest du später mehr oder weniger Rechte geben?

1. Gehe zu dem Produkt (z. B. **https://dash.forgehost.de/domains**)
2. Öffne es → Tab **Teilen**
3. Klicke auf die Person und passe die Rechte an
4. Speichern

### Zugriff entziehen

Soll die Person keinen Zugriff mehr haben?

1. Öffne das Produkt → Tab **Teilen**
2. Klicke auf den **X** oder **Entfernen**-Button neben der Person
3. ✅ Die Person hat sofort keinen Zugriff mehr

---

## Du wurdest eingeladen – so akzeptierst du

### So funktioniert es:

1. Du erhältst eine **E-Mail mit einem Einladungs-Link**
2. Klick auf den Link oder gehe zu **https://dash.forgehost.de/invitations/accept-product**
3. Überprüfe, welches Produkt und welche Rechte dir gegeben werden
4. Klicke auf **Akzeptieren**
5. ✅ Das Produkt erscheint jetzt in deiner Liste!

### Eine Einladung ablehnen

Möchtest du die Einladung nicht annehmen?

1. Klicke auf **Ablehnen**
2. Die Einladung wird gelöscht
3. Später kannst du über die Einladungs-Seite eine neue Einladung akzeptieren

---

## Wichtig zu wissen

::: warning Sicherheit!
**Vollzugriff bedeutet:** Die Person kann alles machen – ähnlich wie wenn sie dein Passwort kennen würde. Gib Vollzugriff nur Personen, denen du 100% vertraust.
:::

::: tip Tipps
- **E-Mail-Adresse:** Die Person muss registriert sein. Wenn sie neu ist, erhält sie einen Registrierungs-Link
- **Unbegrenzte Einladungen:** Du kannst beliebig viele Personen einladen
- **Einladungen verfallen:** Nach einiger Zeit verfallen unakzeptierte Einladungen – einfach erneut senden
:::

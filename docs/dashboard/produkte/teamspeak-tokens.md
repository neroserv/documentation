# TeamSpeak Privilege Tokens erstellen

## Was sind Tokens?

**Privilege Tokens** sind spezielle Schlüssel, die Admin-Rechte auf deinem TeamSpeak Server geben.

---

## Token erstellen

1. Gehe zu **https://dash.forgehost.de/teamspeak-accounts**
2. Klicke auf deinen **TeamSpeak Server**
3. Öffne den Tab **Tokens**
4. Klicke auf **+ Token erstellen**
5. Wähle die **Rechte** (z. B. Channel Admin, Server Admin)
6. Speichern ✅

---

## Token verwenden

1. Kopiere den **Token-Code**
2. Im TeamSpeak Client: Menü → Token verwenden
3. Gib den Token ein
4. 🎉 Du hast die Rechte!

---

## Token löschen

1. Öffne **Tokens** Tab
2. Klicke auf **Löschen** neben dem Token
3. ✅ Token ist inaktiv

# Login & Registrierung

## Anmelden in dein Konto

Du möchtest dich in dein ForgeHost-Konto anmelden? So funktioniert es:

1. Besuche **https://dash.forgehost.de/login**
2. Gib deine **E-Mail-Adresse** ein
3. Gib dein **Passwort** ein
4. Klicke auf den Button **Anmelden**
5. Du bist jetzt eingeloggt und siehst dein Dashboard

**Du hast 2-Faktor-Authentifizierung (2FA) aktiviert?**
Nach dem Login wirst du aufgefordert, einen Code aus deiner Authenticator-App einzugeben. Das ist eine zusätzliche Sicherheitsebene – gib einfach den Code ein.

**Oder über Social Login:**
Falls verfügbar, kannst du dich auch über Google, GitHub oder andere Anbieter anmelden.

## Ein neues Konto erstellen

Noch kein Konto? Kein Problem! So registrierst du dich:

1. Besuche **https://dash.forgehost.de/register**
2. Fülle das Formular aus:
   - Dein **Name**
   - Deine **E-Mail-Adresse** (wird als Anmeldename verwendet)
   - Ein sicheres **Passwort** (mind. 8 Zeichen, mit Großbuchstaben, Zahlen)
3. Klicke auf **Registrieren**
4. Du erhältst eine **Bestätigungsmail**
5. Öffne den Link in der E-Mail oder besuche **https://dash.forgehost.de/email/verify**
6. Dein Konto ist aktiviert und du kannst dich anmelden!

## Passwort vergessen?

Kein Problem, das kann jedem passieren. So setzt du dein Passwort zurück:

1. Gehe zu **https://dash.forgehost.de/forgot-password**
2. Gib deine **E-Mail-Adresse** ein
3. Klicke auf **Passwort zurücksetzen**
4. Du erhältst eine **E-Mail mit einem Bestätigungslink**
5. Klicke auf den Link und gib dein **neues Passwort** ein
6. Speichern und fertig! Du kannst dich jetzt mit deinem neuen Passwort anmelden

::: tip 💡 Gutes Passwort?
Ein starkes Passwort besteht aus:
- Mindestens **8 Zeichen**
- **Großbuchstaben** (A, B, C...)
- **Kleinbuchstaben** (a, b, c...)
- **Zahlen** (1, 2, 3...)
- **Sonderzeichen** (!@#$%)

Beispiel: `MeinSicheres!Pass123`
:::

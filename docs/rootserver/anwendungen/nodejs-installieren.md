# Node.js + npm installieren

## Node.js für deine Anwendungen

**Node.js** ist eine JavaScript-Runtime. Mit **npm** (Node Package Manager) kannst du Pakete verwalten.

---

## Installation über offizielle Paketquellen

```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt update
sudo apt install nodejs -y
```

---

## Version überprüfen

```bash
node --version
npm --version
```

---

## Nächste Schritte

- 📦 Installiere deine **Node-Pakete**
- 🚀 Starte deine **Anwendung**

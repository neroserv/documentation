# btop installieren

## System-Ressourcen überwachen mit btop

**btop** ist ein modernes, visuelles Tool zur Überwachung von CPU, RAM, Festplatte und Netzwerk.

---

## Installation

```bash
sudo apt update
sudo apt install btop -y
```

---

## Verwendung

```bash
btop
```

---

## Shortcuts

- `q` - Beenden
- `p` - Nach CPU sortieren
- `m` - Nach RAM sortieren
- `d` - Nach Festplatte sortieren
- `n` - Nach Netzwerk sortieren

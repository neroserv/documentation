# Java installieren

## Java Runtime für deine Anwendungen

**Java** wird für viele Server-Anwendungen benötigt (Minecraft, Gameserver, etc.).

---

## Installation

```bash
sudo apt update
sudo apt install default-jre default-jdk -y
```

---

## Version überprüfen

```bash
java -version
javac -version
```

---

## Nächste Schritte

- 🎮 Starte deinen **Gameserver**
- ⚙️ Konfiguriere **Java-Einstellungen**

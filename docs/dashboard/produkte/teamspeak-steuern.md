# TeamSpeak Server steuern

## Server verwalten

Dein TeamSpeak Server läuft? So kontrollierst du ihn:

---

## Server öffnen

1. Gehe zu **https://dash.forgehost.de/teamspeak-accounts**
2. Klicke auf deinen **TeamSpeak Server**
3. Du siehst den **Status** und Optionen

---

## Server starten / stoppen

- **Starten:** Button **START** klicken
- **Stoppen:** Button **STOP** klicken
- **Neustarten:** Button **RESTART** klicken

---

## Server-Name ändern

1. Öffne den Tab **Umbenennen**
2. Gib einen neuen Namen ein
3. Speichern ✅

---

## Nächste Schritte

- 🔑 Erstelle **Admin-Tokens**
- 💾 Mache **Backups**
- 📊 Schaue **Statistiken**

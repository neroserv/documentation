# TeamSpeak mieten

## Was ist TeamSpeak?

**TeamSpeak** ist eine Voice-Chat-Lösung. Perfekt für Teams, Gamer und Community-Gruppen!

---

## TeamSpeak Server mieten

1. Gehe zu **https://dash.forgehost.de/teamspeak**
2. Wähle einen **Tarif** (z. B. 32 Slots, 64 Slots)
3. Klicke auf **Bestellen**
4. Im Checkout:
   - Überprüfe die Laufzeit
   - Wähle Zahlungsmethode
5. Zahle → ✅ Server wird erstellt!

---

## Nach der Bestellung

1. Gehe zu **https://dash.forgehost.de/teamspeak-accounts**
2. Dein neuer Server erscheint
3. Du siehst:
   - **Server-Adresse** (IP:Port)
   - **Admin-Token** (zum Login)
   - **Verbindungsdaten**

---

## Server beitreten

1. **TeamSpeak-Client** herunterladen (kostenlos)
2. Client öffnen → Verbinden
3. Gib die **Server-Adresse** ein
4. 🎉 Du bist verbunden!

---
